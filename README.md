# TLU_project

TLU （全称TanLe Upshield）全系列本地数据加密工具，自研加密逻辑，提供字符串加密、多格式文件加密、文件完整性校验功能；搭配 TLU-GUI 可视化图形操作端，简单拖拽/填写数据即可完成加密、校验、解密操
作，用于保护本地敏感文本与资源文件，也可快速核验文件是否被篡改。
