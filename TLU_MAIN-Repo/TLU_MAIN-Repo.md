TLU_MAIN-Repo

**仓库概述**

This is the central root repository for all TLU series resources.

本仓库为 TLU （全称TanLe Upshield）全系列统一总资源库，用于集中存放、归档、管理所有 TLU 相关全套资源，包含各版本程序本体、配套源码、配置文件、辅助工具、文档资料、历史迭代包与附属衍生资源。

所有 TLU 相关内容均统一归集于此目录，方便统一管理、追溯迭代版本、统一分发与归档，不再分散存放各类零散资源。

*仓库包含内容*

-各正式发行版程序本体

-全分支历史迭代版本、存量旧版归档资源

-项目配套文档记录等

-后续新增全部TLU系列衍生资源与拓展内容

**重要声明**

All functions, features and content described in this project introduction, documents and descriptive articles are only general overall descriptions for reference only.

本项目所有简介、正文描述、功能介绍等文案内容，均为全局性整体参考描述，不针对单一具体版本做精准绑定。

因 TLU 拥有多条独立发行分支、多个不同定制版本，各版本会根据预设开发规划进行独立的功能删减、调整与适配优化。无法保证仓库内所有程序版本，均完整包含文档中描述的全部功能。

软件实际内置功能，请以对应程序当前版本真实运行效果为准，无需以项目简介及文本描述作为唯一判定标准。

使用须知

1. 请勿跨版本强行对照功能差异，不同分支版本本身功能配置天生不互通、不一致
2. 仓库仅做资源归集归档，各版本独立维护，不做全版本功能统一对齐
3. 后续所有 TLU 新增资源，均统一归档至本总仓库，不新建独立零散仓库
